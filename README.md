# pocketransport
<img width="3456" height="1728" alt="pocketransport(1)" src="https://github.com/user-attachments/assets/4b9a8dd3-539b-4780-b6ec-243e97c871bb" />
tiny little thing that lets you check what buses are coming next from the closest bus stop from you, pulled from GPS data and local GTFS data. it has a ESP32-S3, a Xiao Round Screen and a L76K GNSS module so it can find the closest bus stop next to you
